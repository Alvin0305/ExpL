## Label Translation

- Output of code generation contains labels which XSM does not understand.
- XSM does not support labels, it supports only addresses
- So, we need to translate each label to addresses. That process is called label translation. 
- This is done by label_lexer.l file which will parse the code generated by our compiler(containing labels) and replace the labels with their addresses.
- The label translation is a two parse process. 
    - On the first parse, we save the addresses of the labels in a data structure called Label Table. 
    - On the second parse, we will replace the labels with their addresses.
    - Label Table will have the name of the label with their address being populated in the first parse.
